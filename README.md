# PredictX – AI Multi-Disease Prediction System

![PredictX Hero](frontend/src/assets/hero.png)

A comprehensive multi-disease prediction platform designed to predict heart disease, diabetes, breast cancer, and lung cancer. PredictX offers an intuitive, modern interface for users to input data and receive health predictions, enhancing the diagnostic experience.

## 🛠️ Technology Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS v4, Framer Motion, Axios, React Hook Form
- **Backend:** Node.js, Express.js
- **Machine Learning Models:** Logistic Regression, SVM, CNN, InceptionResNet

## 🩺 Machine Learning Modules

1. **Heart Disease Prediction (Logistic Regression):** Analyzes 13 clinical parameters including cholesterol, resting blood pressure, and ECG results.
2. **Diabetes Prediction (SVM):** Evaluates factors such as glucose levels, BMI, and insulin.
3. **Breast Cancer Prediction (CNN):** Classifies histology images as malignant or benign.
4. **Lung Cancer Prediction (InceptionResNet):** Detects cancerous nodules in uploaded lung CT scans.

## ⚠️ Medical Disclaimer

PredictX is an educational and research-oriented machine learning project. Predictions are model outputs and are not a medical diagnosis. Always consult a qualified healthcare professional for medical decisions.
